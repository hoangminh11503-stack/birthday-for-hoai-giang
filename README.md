# 🎂 Thiệp Chúc Mừng Sinh Nhật Chị Hoài Giang ✨

> Một trang web thiệp sinh nhật online 1 trang được thiết kế theo phong cách **Luxury, Artistic, Fantasy & Elegant**. Trang web ngập tràn hiệu ứng động lộng lẫy: cánh hoa hồng 3D bay lượn, đàn bươm bướm ngũ sắc vỗ cánh trong không gian, bụi sao lấp lánh, pháo hoa giấy chúc mừng, bánh sinh nhật tương tác có thể thổi nến ước nguyện và âm nhạc du dương.

---

## 🌟 Tính Năng Nổi Bật

1. **Màn hình chào lộng lẫy (Cover Screen)**:
   - Dòng chữ lớn lấp lánh: **Happy Birthday Hoài Giang** với hiệu ứng ánh kim vàng hồng (Rose Gold & Gold Foil Shimmer).
   - Nút **"Mở Thiệp"** phát sáng với hiệu ứng sóng ánh sáng thôi thúc người xem chạm vào mở quà.
2. **Hiệu ứng chuyển cảnh huyền diệu**:
   - Khi nhấn "Mở Thiệp": Chuông ngân huyền bí reo vang, đàn bươm bướm bay vút lên, pháo hoa confetti bùng nổ, cánh hoa hồng túa ra và nhạc nền tự động cất lên.
3. **Cánh hoa hồng 3D & Hoa nở rơi liên tục**:
   - Tự động xoay lật 3 chiều theo chuyển động gió tự nhiên, mềm mại và chân thực trên canvas 60fps.
4. **Vườn bươm bướm 3D bay lượn (3D Butterflies)**:
   - Đàn bướm nhiều màu sắc (Hồng Rose, Vàng Hoàng Gia, Tím Thần Tiên, Ngọc Lam, Hồng Ngọc) với đôi cánh vỗ nhịp 3D sống động bay lượn tự do.
5. **Bánh sinh nhật tương tác (Thổi nến & Ước nguyện)**:
   - Bánh kem 2 tầng trang trí dâu tây & cherry với 3 ngọn nến lung linh.
   - Người nhận có thể **chạm vào bánh** để thổi tắt nến, khói bay lên, nhận thông điệp chúc phúc và bắn pháo hoa ăn mừng!
6. **Âm thanh du dương & Nút điều khiển thông minh**:
   - Nút bật/tắt nhạc nổi góc trên bên phải với đĩa than xoay tròn và vạch sóng equalizer nhảy theo nhạc.
   - Tích hợp sẵn bản nhạc sinh nhật âm hưởng hộp âm nhạc / chuông ngân du dương, hoạt động trơn tru cả khi offline hay online.
7. **Tối ưu Mobile First & Responsive hoàn hảo**:
   - Hiển thị hoàn mỹ trên mọi dòng điện thoại (iPhone, Samsung, Xiaomi...) cũng như máy tính bảng và màn hình máy tính lớn (có hiệu ứng nghiêng 3D theo chuột trên máy tính).

## 📁 Cấu Trúc Thư Mục

```text
Chúc mừng sinh nhật/
│
├── index.html        # Khung giao diện HTML5 chuẩn SEO & OpenGraph
├── style.css         # Toàn bộ hiệu ứng CSS3, 3D transform, Glassmorphism
├── script.js         # Canvas cánh hoa 3D, đàn bướm, pháo hoa, âm thanh
├── deploy.bat        # File chạy tự động đẩy code lên GitHub bằng Git Credential Manager
├── assets/           # Thư mục chứa tài nguyên âm thanh & hình ảnh
│   └── birthday.wav  # File nhạc sinh nhật âm hưởng hộp nhạc du dương
└── README.md         # Hướng dẫn chi tiết & deploy
```

## 🌐 Hướng Dẫn Deploy Lên GitHub Pages (`birthday-for-hoai-giang`)

### Cách 1: Tự động bằng Git Credential Manager (Khuyên dùng)
1. Tạo repo [birthday-for-hoai-giang](https://github.com/new) trên GitHub (chọn **Public**).
2. Nhấp đúp vào file `deploy.bat` trong thư mục này.
3. Trình duyệt sẽ mở ra trang xác nhận OAuth của GitHub. Bạn chỉ cần bấm **"Authorize GitCredentialManager"**.
4. Vào [Settings > Pages](https://github.com/hoangminh11503/birthday-for-hoai-giang/settings/pages), chọn branch `main` và bấm **Save**.
5. Đường link gửi chị Hoài Giang:
   👉 **`https://hoangminh11503.github.io/birthday-for-hoai-giang/`**
